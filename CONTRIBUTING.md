# Contributing

This repository is intentionally limited to the public product shell.

Suitable contributions include:

- corrections to public methodology or source documentation;
- improvements to public product wording;
- public-safe schema/documentation changes;
- synthetic demonstration improvements.

Do not submit:

- proprietary engine code;
- operational parsers or SQL migrations;
- authentication/deployment/recovery implementation;
- real asset/customer/portfolio data;
- raw or cached source datasets;
- credentials, tokens, keys or private URLs.

Use synthetic material only.

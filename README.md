# Bangladesh Climate & Location Risk Intelligence

Public code, schemas, and methodology for a location-level physical climate and operational-risk intelligence engine for Bangladesh.

The project connects geocoded assets with transparent hazard, exposure, logistics, and portfolio diagnostics while preserving source provenance and avoiding opaque composite risk scores.

## Public repository boundary

This repository contains software, schemas, methodology, documentation, tests, and synthetic examples only.

It intentionally excludes real factory/asset coordinate databases, DIFE-enriched establishment records, raw or cached raster/PBF/source files, customer or financial portfolio data, credentials, private source snapshots, and proprietary production outputs.

## Core principles

- Hazard is not loss.
- No arbitrary composite climate-risk score.
- Fine-resolution analysis requires defensible site coordinates.
- Observed, modelled, reanalysis, and calculated values remain distinct.
- Second- and third-order effects must be traceable to data and research evidence.
- Missing or ambiguous inputs fail closed rather than being fabricated.
- Portfolio workflows use pseudonymous identifiers and minimum necessary data.

## Status

The public repository contains the software and methodology baseline. Production databases and live asset intelligence are maintained separately.

# Source catalogue

The engine is designed around public or lawfully accessible sources including:

- JRC/CEMS global river-flood hazard layers
- Copernicus Global Flood Monitoring
- CHIRPS rainfall
- ECMWF/Copernicus ERA5-Land
- Copernicus DEM / SRTM-type terrain products
- BWDB/FFWC water-level data
- NOAA IBTrACS cyclone tracks
- WorldPop / GHSL / ESA WorldCover contextual layers
- Bangladesh administrative geography from official sources
- OpenStreetMap/Geofabrik for road-network analysis

Each production observation should retain provider, dataset/version, measurement basis, retrieval time, valid period, spatial resolution, units, method version, and immutable artifact/source hash where applicable.
